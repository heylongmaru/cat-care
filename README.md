# 🐾 貓咪照護日誌（cat-care）

記錄貓咪的大小便（次數與狀態）、飲食（自動換算水分與熱量）、喝水、體重與異常事件；
支援多貓、獸醫報告匯出，並可透過你自己的 Google 試算表讓多台裝置／多位照顧者共同記錄。

- `index.html`：工具本體（單檔，離線可用）
- `guide.html`：使用說明＋雲端同步逐步教學
- `sync-appscript.gs`：Google Apps Script 同步後端（貼進你自己的試算表）

## 快速開始
1. 開 `index.html` → 新增貓咪 → 記一次體重
2. 設定 → 食物庫：填你家食物的含水量％與熱量（看包裝）
3. 「今日」頁點大按鈕隨手記

## 計算公式（參考值，非醫療建議）
- 總攝水 ＝ 喝水 ＋ Σ(實吃克數 × 含水量％)；建議量預設 50 ml/kg/日（可調）
- 熱量需求 DER ＝ 70 × 體重^0.75 × 係數（預設 1.2 已絕育成貓，可調）

資料存於各裝置瀏覽器（localStorage）；備份用「設定 → 匯出 JSON」或開雲端同步。
